## This is the backend for the blue bins application

### Business rules
1. A user can only have one active booking at a time, they can update the booking up to, but not including the collection date.


2. A booking can only have one location, one schedule, and one set of recycling.

3. If the location of a booking is changed so to must the collection date

4. A user can have a default location, which will be used by default, but if the location is different from the default it will override the default, same with schedule

5. A user can change their default booking location and schedule when they create a new booking
